# Guide Bornes de Recharge pour Vehicules Electriques

Bienvenue dans ce guide pratique consacre a l'installation de bornes de recharge pour vehicules electriques en France.

## Pourquoi installer une borne a domicile ?

Recharger votre vehicule electrique a domicile est la solution la plus pratique et economique. Avec une borne murale, vous divisez le temps de recharge par 3 a 8 par rapport a une prise standard.
